<h1> Software Developer - FullStack ツ </h1>

Desenvolvedor Full Stack com experiência em aplicações web escaláveis e **desenvolvimento com IA (Claude)**, atuando no backend e frontend com **Node.js**, **NestJS**, **PHP**, **Laravel**, **React** e **Vue.js**; sempre com TypeScript, **SOLID** e **Clean Architecture**.

- Backend, trabalho com microsserviços, APIs REST, **RabbitMQ**, **Redis**, **AWS S3**, **Cloudflare R2** e **PostgreSQL**. Ambientes containerizados com **Docker** e **Kubernetes** fazem parte do meu dia a dia.
- Frontend, desenvolvo interfaces modernas com **React** e **Vue.js**, usando **Shadcn/UI** e **Lucide React**, com fidelidade ao design system e integração via **Figma**.
- Desenvolvimento com IA, trabalho com o **Claude** no dia a dia e tenho conhecimento em **harnesses** e **patterns** que tornam o desenvolvimento com agentes de IA mais previsível: contexto bem definido, tarefas delimitadas, ferramentas controladas e validação por testes automatizados e code review.
- Fluxo de trabalho, uso o **Orca.dev**, um ambiente de desenvolvimento de agentes, para organizar o desenvolvimento com Claude, com worktrees Git isoladas e agentes em paralelo.

Já atuei no **Garupa App**, **Aride Brasil** e **HelperRecruiter**. Tenho experiência com testes automatizados, code reviews e metodologias ágeis.
